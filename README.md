# casaos-custom-favicon
a mod to be used in hand with CasaMOD by @Cp0204 meant for CasaOS. allows changing the favicon of the CasaOS tab. The image must be named "favicon" and must be in the .ico format. 

the favicon.ico that comes with this mod is just da epic face, you dont need it. you can use any .ico file. the mod.js is the only important file. add it to Root>DATA>AppData>casamod>mod

this wouldnt have been possible without CasaMOD and CasaOS so thank you to their respective creators and collaborators.
